# VSM System 1 (Biophysical) Verification

This directory contains scripts to validate the outputs of the VSM System 1 module.

## Scripts

-   `01_validate_rpp_baseline.py`: This script is crucial. It performs a plausibility check on the "Realistic Physical Potential" (RPP) baseline generated by the calibrated WOFOST runs. You should use the plots generated by this script to confirm that the RPP is behaving as a reasonable, realistic upper bound for the final yield.
-   `02_analyze_biophysical_engine.py`: This script analyzes the VSM 1 "Expert Engine." Use the component loading plots it generates to ensure that the principal components are combining the RPP outputs and static features in an interpretable way.
