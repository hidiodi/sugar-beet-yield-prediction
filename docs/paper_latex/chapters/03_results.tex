\subsection{Anomaly Forensics (Black Swan Events)}
\begin{itemize}
    \item \textbf{2003 (Historic Heat/Drought):} Actual 516.9 dt/ha.
    \begin{itemize}
        \item \textbf{Super Ensemble (SEAS5):} 581.9 (MAE 80.7). Even with forecast uncertainty, the Bio-Physical Scanner successfully identified the heat stress signal in the SEAS5 ensemble members.
        \item Trend: 593.7 (MAE 95.8).
    \end{itemize}
    \item \textbf{2014 (Bumper Year):} Actual 825.6 dt/ha.
    \begin{itemize}
        \item \textbf{Super Ensemble:} 749.5 (MAE 84.3) - \textit{Correctly captures the upside.}
        \item Trend: 715.9 (MAE 114.0)
    \end{itemize}
    \item \textbf{2018 (Severe Drought):} Actual 628.5 dt/ha.
    \begin{itemize}
        \item \textbf{Super Ensemble:} 710.8 (MAE 103.5) - \textit{Significantly better than trend.}
        \item Trend: 799.7 (MAE 182.1) - \textit{Failed to predict magnitude of loss.}
    \end{itemize}
\end{itemize}

\subsection{Ablation Study}
To quantify the contribution of specific components, we performed an ablation study (Figure \ref{fig:ablation}) by systematically removing key modules and measuring the impact on forecast skill.

\begin{itemize}
    \item \textbf{No Stress Signals:} Removing the Bio-Physical Scanner features (e.g., Anoxia, Scorch) caused a sharp decline in performance during extreme years, with the MAE for 2018 increasing by over 15\%. This confirms that standard weather variables alone are insufficient for capturing physiological thresholds.

    \item \textbf{No Meta-Learner:} Replacing the dynamic gating with a static "Equal Weight" ensemble reduced the global $R^2$ from 0.618 to 0.552. This demonstrates that the "Regime Switching" logic adds significant value beyond simple model averaging.

    \item \textbf{Data Quality Filter:} Crucially, we tested the model trained on the full dataset (including "Oracle Errors" $> 200$ dt/ha) versus the cleaned dataset. The inclusion or exclusion of this filter resulted in a \textbf{negligible performance difference} ($< 0.5\%$ change in Skill Score). This empirical validation confirms that our results are driven by the physics-informed architecture and not by "cherry-picking" easy data points.
\end{itemize}
