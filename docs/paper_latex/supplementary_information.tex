\section{Extended Mechanistic Formulas}
The \textbf{Compound Failure Index} identifies yield crashes by aggregating stress vectors derived from WOFOST internal moisture balances \citep{boogaard1998wofost} and SEAS5 anomalies.

\textbf{$M_3$ Bio-Physical Limits Logic}:
The $M_3$ model applies a hierarchical decision tree to adjust the trend baseline ($Y_{trend}$):
\begin{enumerate}
    \item \textbf{Water Crash:} If $Z_{water} < -0.95$:
    \[ M_3 = Y_{trend} \times \left(1.0 - \left(0.15 + |Z_{water} + 0.95| \times 0.25\right)\right) \]
    \item \textbf{Bumper Potential:} If $Z_{water} > 1.0$ AND $Z_{solar} > -1.0$:
    \[ M_3 = Y_{trend} \times \left(1.0 + \left(0.05 + (Z_{water} - 1.0) \times 0.05\right)\right) \]
    \item \textbf{Else:} $M_3 = Y_{trend}$
\end{enumerate}

\textbf{Scorch Index} (Heat + Drought interaction):
\begin{equation}
    \text{Scorch} = \max\left(Z_{\text{heat}} \times (-Z_{\text{bal}})^+ , \left(Z_{\text{heat}} - 1.5\right)^+ \times 2.0\right)
\end{equation}

\textbf{Drown Index} (Anoxia/Waterlogging):
\begin{equation}
    \text{Drown} = (Z_{\text{anoxia}} - 0.8)^+ \times 2.0
\end{equation}

\textbf{Late Start Index} (Sowing delay):
\begin{equation}
    \text{LateStart} = (Z_{\text{sow}} - 1.5)^+ \times 2.0
\end{equation}

\textbf{Skill Score}:
The skill score quantifies the improvement of the ensemble model relative to the statistical trend baseline:
\begin{equation}
    \text{Skill Score} = \left(1 - \frac{\text{MAE}_{\text{Ensemble}}}{\text{MAE}_{\text{Trend}}}\right) \times 100
\end{equation}
