\section{Predictive Algorithms \& Hyperparameters}
The physically-gated anomaly detector utilizes specialized components configured for operational stability.

\subsection{Model A: The Hybrid Detector ($M_{\text{hybrid}}$)}
The hybrid detector is an XGBoost model designed to predict yield deviations from the trend. The \textbf{Target} is defined as $\log(y_t / M_{\text{trend}}(t))$, clipped symmetrically at $[-0.6, 0.6]$. The model uses a set of 106 comprehensive \textbf{Features}, including $D_{\text{sow}}$, $S_{\text{heat}}$, and outputs from the physical prior. To prevent overfitting, the \textbf{Hyperparameters} are heavily regularized (\texttt{max\_depth=5}, \texttt{reg\_lambda=2.0}, \texttt{learning\_rate=0.05}).

\subsection{Model B: The Physical Prior ($M_{\text{phys}}$)}
The physical prior is a climatological ensemble of WOFOST (v7.2) simulations. Its \textbf{Configuration} consists of 30 parallel simulations. The simulations run on \textbf{Weather Traces} from historical weather data spanning 1995--2024. The model \textbf{Initialization} uses the current year's soil moisture and temperature (as of March 1st). Finally, the \textbf{Outputs} provided are the Expected Physical Yield ($Y_{\text{phys}}$) and the Downside Risk (10th percentile).

\subsection{Asymmetric Threshold Gate}
The gate determines the final forecast by comparing the hybrid detector ($M_{\text{hybrid}}$) with the statistical trend ($M_{\text{trend}}$). The system applies a trigger mechanism when the deviation, defined as $\text{Dev}(t) = (M_{\text{hybrid}}(t) - M_{\text{trend}}(t))\, /\, M_{\text{trend}}(t)$, exceeds a magnitude of $0.04$.

When triggered, the system applies asymmetric weighting depending on the direction of the anomaly. On the downside (``crash'' signal), the system places full trust in the physical model, setting the final forecast to match the hybrid detector's prediction. On the upside (``bumper'' signal), the system applies a conservative 50\% trust, blending the hybrid prediction equally with the statistical trend. If the deviation does not exceed the trigger threshold, the system defaults to the ``safety mode,'' fully relying on the statistical trend.

Formally, the final forecast is:
\begin{equation*}
\resizebox{\columnwidth}{!}{%
$Y_{\text{final}}(t) = \begin{cases}
M_{\text{hybrid}}(t) & \text{if } \text{Dev}(t) < -0.04 \\
0.5\, M_{\text{hybrid}}(t) + 0.5\, M_{\text{trend}}(t) & \text{if } \text{Dev}(t) > +0.04 \\
M_{\text{trend}}(t) & \text{otherwise.}
\end{cases}$%
}
\end{equation*}
