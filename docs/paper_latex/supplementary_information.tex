\section{Predictive Algorithms \& Hyperparameters}
The Physically-Gated Anomaly Detector utilizes specialized components configured for operational stability.

\subsection{Model A: The Hybrid Detector ($M_{hybrid}$)}
The Hybrid Detector is an XGBoost model designed to predict yield deviations from the trend.
\begin{itemize}
    \item \textbf{Target:} $\log(Y_{actual} / Y_{trend})$, clipped symmetrically at $[-0.6, 0.6]$.
    \item \textbf{Features:} 106 "Unleashed" features, including `sowing_doy`, `heat_signal`, and outputs from the Physical Prior.
    \item \textbf{Hyperparameters:} heavily regularized to prevent overfitting:
    \begin{itemize}
        \item \texttt{max\_depth=5}
        \item \texttt{reg\_lambda=2.0}
        \item \texttt{learning\_rate=0.05}
    \end{itemize}
\end{itemize}

\subsection{Model B: The Physical Prior ($M_{phys}$)}
The Physical Prior is a Climatological Ensemble of WOFOST (v7.2) simulations.
\begin{itemize}
    \item \textbf{Configuration:} 30 parallel simulations.
    \item \textbf{Weather Traces:} Historical weather data from 1995--2024.
    \item \textbf{Initialization:} Current year's soil moisture and temperature (March 1st).
    \item \textbf{Outputs:} Expected Physical Yield ($Y_{phys}$) and Downside Risk (10th percentile).
\end{itemize}

\subsection{Asymmetric Threshold Gate}
The Gate determines the final forecast by comparing the Hybrid Detector ($M_{hybrid}$) with the Statistical Trend ($M_{trend}$).

\begin{enumerate}
    \item \textbf{Trigger:} Activate if $|M_{hybrid} - M_{trend}| > 4.0\%$.
    \item \textbf{Downside Trust (Crash):} If Triggered AND $M_{hybrid} < M_{trend}$:
    \[ Y_{final} = 1.0 \times M_{hybrid} \]
    (Trust the Crash signal fully).
    \item \textbf{Upside Trust (Bumper):} If Triggered AND $M_{hybrid} > M_{trend}$:
    \[ Y_{final} = 0.5 \times M_{hybrid} + 0.5 \times M_{trend} \]
    (Blend the Bumper signal conservatively).
    \item \textbf{Default (Safety Mode):} Else:
    \[ Y_{final} = M_{trend} \]
\end{enumerate}
