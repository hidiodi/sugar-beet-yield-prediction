\section{Predictive Algorithms \& Hyperparameters}
The Physically-Gated Anomaly Detector utilizes specialized components configured for operational stability.

\subsection{Model A: The Hybrid Detector ($M_{\text{hybrid}}$)}
The Hybrid Detector is an XGBoost model designed to predict yield deviations from the trend.
\begin{itemize}
    \item \textbf{Target:} $\log(Y_{\text{actual}} / Y_{\text{trend}})$, clipped symmetrically at $[-0.6, 0.6]$.
    \item \textbf{Features:} 106 ``Unleashed'' features, including $D_{\text{sow}}$, $S_{\text{heat}}$, and outputs from the Physical Prior.
    \item \textbf{Hyperparameters:} heavily regularized to prevent overfitting:
    \begin{itemize}
        \item \texttt{max\_depth=5}
        \item \texttt{reg\_lambda=2.0}
        \item \texttt{learning\_rate=0.05}
    \end{itemize}
\end{itemize}

\subsection{Model B: The Physical Prior ($M_{\text{phys}}$)}
The Physical Prior is a Climatological Ensemble of WOFOST (v7.2) simulations.
\begin{itemize}
    \item \textbf{Configuration:} 30 parallel simulations.
    \item \textbf{Weather Traces:} Historical weather data from 1995--2024.
    \item \textbf{Initialization:} Current year's soil moisture and temperature (March 1st).
    \item \textbf{Outputs:} Expected Physical Yield ($Y_{\text{phys}}$) and Downside Risk (10th percentile).
\end{itemize}

\subsection{Asymmetric Threshold Gate}
The Gate determines the final forecast by comparing the Hybrid Detector ($M_{\text{hybrid}}$) with the Statistical Trend ($M_{\text{trend}}$). The system applies a trigger mechanism when the deviation, defined as $\text{Dev}(t) = (M_{\text{hybrid}}(t) - M_{\text{trend}}(t))\, /\, M_{\text{trend}}(t)$, exceeds a magnitude of $0.04$.

When triggered, the system applies asymmetric trust depending on the direction of the anomaly. On the downside (``Crash'' signal), the system places full trust in the physical model, setting the final forecast to match the Hybrid Detector's prediction. On the upside (``Bumper'' signal), the system applies a conservative 50\% trust, blending the Hybrid prediction equally with the Statistical Trend. If the deviation does not exceed the trigger threshold, the system defaults to the ``Safety Mode,'' fully relying on the Statistical Trend.

Formally, the final forecast is:
\begin{equation*}
\resizebox{\columnwidth}{!}{%
$Y_{\text{final}}(t) = \begin{cases}
M_{\text{hybrid}}(t) & \text{if } \text{Dev}(t) < -0.04 \\
0.5\, M_{\text{hybrid}}(t) + 0.5\, M_{\text{trend}}(t) & \text{if } \text{Dev}(t) > +0.04 \\
M_{\text{trend}}(t) & \text{otherwise.}
\end{cases}$%
}
\end{equation*}
